# A03〜A05 素材登録・下書き編集・表示確認の操作デモ

開発サーバーを `npm run dev` で起動し、[/admin-demo](http://localhost:5173/admin-demo) を開く。D担当のA03・A04・A05を確認する独立した入口で、旅行者の全国地図は従来の `/` から使う。A05は管理画面内の表示確認で、実際の旅行者画面を変更するものではない。

これは**未認証の操作デモ**。実在の自治体管理者として認証・所属確認した画面ではない。架空自治体だけを使用し、実API、Firebase保存、Gemini、写真判定、公開処理には接続しない。画像は権利を確認できるテスト用素材で試す。

## 今回の範囲

- A03→A04→A05の手順で素材登録・文章編集・表示確認を行う。A05の写真判定試験は未接続。
- 対象名、根拠情報、撮影に必要な条件（船上・海上／有料施設内の2項目）、料金、撮影上の注意、写真の出典・権利を入力する。従来の6種類の交通手段・必須交通手段の選択は廃止する。
- アクセス補足・利用時間をクリア後の案内用として残し、自治体のアピールコメント・解説の入力欄を追加する。
- 公開探索エリアは自治体の行政区域から自動設定する構想。デモでは架空自治体のエリア名だけを示し、行政区域データの取得や地理的検証は行わない。
- 非公開撮影地点・半径は値を持たず、設定状態だけを示す。実際の設定・取得・所属認可は未接続。
- 参考写真を選択し、ローカルプレビュー、変更、削除ができる。ファイル形式・サイズの制限はデモのブラウザ保護用で、本番のO-03を確定するものではない。
- 入力・画像はReactの状態だけに保持し、コンポーネントの破棄・再読込で初期化する。サーバー送信、端末ストレージへの保存は行わない。ブラウザの戻る・進むキャッシュから同じページが復元される場合まで、離脱時の消去を保証するものではない。
- 非公開参考写真を公開ヒント写真に転用しない。公開ヒント用画像の作成・権利確認は後続の別工程。

## A担当との接続事項

既存の旅行者向け共通DTO・APIは変更しない。以下は管理APIを実装する前にA担当と共同で確定する。

1. サーバーで確認した所属・役割と、自治体行政区域から返す公開探索エリア。
2. `ManagedQuest` の下書き項目、船上・海上と有料施設内での撮影の必須条件、事前の料金・撮影注意、クリア後用のアクセス・利用時間・自治体コメント・解説、出典・権利情報の契約。既存の交通手段配列を新たなAPI契約として採用しない。
3. 参考写真の用途別assetId、認可付き取得、形式・容量・内容検査。参考画像と公開ヒント画像は別用途で管理する。
4. 非公開撮影範囲の設定状態と、認可された設定操作。公開DTOに座標・半径・参考写真を混ぜない。
5. 下書き保存・競合検出用revision、エラー・再試行、AI生成依頼の接続。フォームの値を所属や権限の根拠にしない。

## A04の編集と素材の保持

現在のフォームはローカル表示用の状態で、API契約ではない。親の管理デモがA03・A04の状態を保持し、往復しても素材入力・参考写真・編集した文章を保持する。画像URLはステップ切替では解放せず、写真の置換・削除・親コンポーネントの破棄で解放する。実保存を追加する際は、破棄・保持の説明とテストを同時に更新する。

A03で対象名・根拠を入力してからA04へ進む。A04は問題タイトル・本文・3段階ヒント・確認済み特徴・生成根拠のメモを手動で編集する画面。初期値は空で、明示操作で固定の架空サンプルを読み込める。AI生成ではなく、登録素材から事実を推論・検証するものでもない。編集済み内容へのサンプル再読込は、置換の確認・取消を挟む。

A03の素材を変更しても既存の文章は上書きせず、素材との再確認が必要なことをA04で知らせる。根拠・出典は人が確認する材料で、入力しただけで安全・権利確認や正解の検証が完了したと扱わない。参考写真をA04のヒント画像へコピーせず、ヒント画像は未設定として示す。

将来のAI接続では登録済みの確認材料から生成し、結果は検証・編集が必要な下書きとして扱う。参考写真を公開プレビューへ自動表示せず、A05の試験で旅行者の発見記録を作らない。生成・試験・公開の成功表示は各サーバー処理の実装と検証後に追加する。

## A05 管理画面内の旅行者向け表示確認

A04から表示プレビューへ進み、「挑戦前の問題」と「クリア後の解説（デモ）」を分けて確認する。挑戦前は問題タイトル・問題文・段階ヒント、架空の公開探索エリア、料金・撮影上の注意を表示し、問題の端に選択した撮影条件のアイコンと意味を示す。船上・海上と有料施設内は独立に選択でき、両方選択も可能。場所までの移動手段を表すものではなく、その条件で撮影しないと対象を撮れない場合に選ぶ。未選択を無料・陸上撮影可能との保証として扱わない。

クリア後用のアクセス補足・利用時間・自治体のアピールコメント・解説は、専用の表示確認でだけ確認する。管理用の切替であり、実際にクリアしたことや閲覧権限を証明しない。撮影可能時間や安全・通行の制約は「撮影時の注意」に入力し、挑戦前に知らせる。

ヒントは個別に開閉でき、未入力の項目は未入力として示す。A04へ戻って編集でき、再度プレビューすると最新の入力を反映して挑戦前表示・ヒントを閉じた状態から始める。未入力でも表示の確認はできるが、公開可能との判定ではない。

各プレビューコンポーネントには表示対象の項目だけを個別に渡す。挑戦前のコンポーネントにはアクセス・利用時間・自治体コメント・解説も渡さない。管理内部の対象名・根拠・確認済み特徴・人のメモ・写真の出典と権利・参考写真のFileやURL・非公開設定は両方の表示確認から除外する。全てのフォーム状態を公開データとして扱わず、公開ヒント画像は未設定のままで参考写真を流用しない。A03〜A05の切替で入力・写真・文章は保持し、写真のURLは切替だけで解放しない。

画面は管理用の未公開プレビューと明示する。実際の旅行者画面、実API、カメラ・位置情報、写真判定、試験成功、保存・公開には接続しない。表示内容を手動で確認したことを、正解判定や公開前試験の合格として記録しない。

後続の写真判定試験と公開はA担当との接続事項。素材や文章を変更した後に過去の試験結果を有効と扱わない契約を共同で確定する。
