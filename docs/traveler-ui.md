# 旅行者向けUIの現在の範囲

2026-11-05。「すっきりした旅行アプリ」というユーザーの選択に合わせ、T01/T02の入口を整えた。アプリ名や製品要件の変更はない。

## 使える操作

- 地図のデモマーカーか問題カードから、同じ架空の1問を開く。マーカー選択時はカードまで移動する。
- 静的な地図プレビューを100〜200%に拡大・縮小し、初期表示に戻す。
- 未ログインで問題を閲覧し、挑戦ボタンから既存のGoogleログインを開始する。取消・失敗でも問題を保持し、ログアウトもできる。
- PCでは地図とカードを横に置き、スマホでは縦に並べる。キーボードのフォーカス、本文への移動、動きを減らす設定に対応する。

認証の設定手順は[Firebase接続ガイド](firebase-auth.md)を使う。実設定は`.env.local`だけに置く。

## デモと未実装の境界

地図はSVGのデザインプレビュー。表示倍率は画像全体の拡大で、地図APIのズームではない。移動・地名検索・現在地・実際の問題取得はまだない。マーカーは正解地点ではなく架空の表示位置で、現地への移動・撮影はできない。

既定は既存の`demoQuest`を表示する。[開発用APIモード](local-api.md)を明示した場合だけ、サーバーの架空の1問を取得し、Googleログイン後にサーバーでuidを確認する。取得・認証確認の失敗時にサンプルへ自動で切り替えない。ログイン後も同じ問題を表示し、明示的な操作で[撮影と写真確認](camera-preview.md)を試せる。「自分の記録」は準備中の無効な操作として表示する。GPS・写真送信・判定・保存は追加していない。

B担当が実地図と問題取得を接続する際は、[共通API](api.md#8-最初の共通api実装)を使う。公開探索エリアの代表点と非公開の正解地点を分ける。今回の表示位置を実データとして流用しない。

## 地形の出典

地図のSVGは[Natural Earthの1:110m国境データ](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)から、日本と周辺の地形をMercator投影して簡略化した。データは[パブリックドメイン](https://www.naturalearthdata.com/about/terms-of-use/)。SVG内にも取得元と取得データのSHA256を記録した。

- [`japan-overview.svg`](../src/assets/japan-overview.svg)：スマホ向け。
- [`japan-overview-wide.svg`](../src/assets/japan-overview-wide.svg)：同じ地形を横長に配置したPC向け。

低解像度の概観であり、小島や境界の精密な表示には使わない。正解位置、実写真、個人の行動履歴は含まない。コンパス等の小さなアイコンはコードで作成し、外部画像や新しい依存パッケージは追加していない。

## 確認範囲

`npm run check`で型・lint・テスト・ビルドを確認する。既存の認証テストに加え、地図のデモ表示・倍率の復元・マーカーから同じ問題を開く操作と、明示的なAPI接続の成功・失敗を確認する。

ブラウザの1440px・375px・320px幅で表示を確認し、狭い画面で横にはみ出さないこと、マーカー選択で問題へ移動すること、拡大と初期表示への復帰を確認した。実スマートフォンでの操作と、このUI変更後の実Googleログインの再確認は未実施。認証処理自体は変更していない。
