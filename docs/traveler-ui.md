# 旅行者向けUIの現在の範囲

2026-11-05。ユーザーが選んだNeobrutalismの方向で、旅行者画面と自治体デモのUIを揃えた。全国地図を入口にする構成、アプリ名、製品要件、既存の認証・撮影・API処理は維持する。

## 共通の表示ルール

- `src/theme.css`で色・枠線・角丸・影・文字の強弱を共有する。生成りの背景に黒い2pxの枠線、黄色の主操作、黄緑のイラスト、水色の地図を使う。
- 操作ボタンは44px以上を基本にし、押すと影に沈む表現にする。無効な操作は灰色で区別し、キーボードのフォーカスは青い輪郭で示す。動きを減らす設定では移動を止める。
- 地図、問題詳細、地域・問題の選択、ログイン状態、撮影・写真確認、取得中・0件・失敗・再試行を同じ配色に揃える。
- `/admin-demo`の素材登録・下書き編集・旅行者向け表示確認も同じテーマを使う。デモ・未接続の注意や非公開情報の扱いは変えない。
- SVGは既存の地形と出典を保ち、配色のみ変更する。新しい依存や外部フォントは追加しない。

## 使える操作

- 公開APIから取得した問題一覧で1問を選び、詳細を開く。ローカルAPIは架空の3問を返す。APIモードでは固定デモマーカーを表示しない。
- 「全国」または公開地域を選び、地域ごとの公開問題に絞り込む。地域名と問題数を表示し、0件でも別地域や全国へ戻れる。
- 静的な地図プレビューを100〜200%に拡大・縮小し、初期表示に戻す。
- 未ログインで問題を閲覧し、挑戦ボタンから既存のGoogleログインを開始する。取消・失敗でも問題を保持し、ログアウトもできる。
- PCでは地図とカードを横に置き、スマホでは縦に並べる。キーボードのフォーカス、本文への移動、動きを減らす設定に対応する。

認証の設定手順は[Firebase接続ガイド](firebase-auth.md)を使う。実設定は`.env.local`だけに置く。

## デモと未実装の境界

地図はSVGのデザインプレビュー。表示倍率は画像全体の拡大で、地図APIのズームではない。移動・地名検索・現在地はまだない。公開APIから問題を取得するが、応答自体は架空データであり、現地への移動・撮影はできない。

通常の起動画面では公開APIから問題一覧・詳細・地域名を取得する。失敗時は再試行を表示し、固定`demoQuest`へ切り替えない。「自分の記録」は準備中の無効な操作として表示する。最新mainの[撮影と写真確認](camera-preview.md)も維持する。APIモードではサーバーでログインを確認した後、明示的な操作で端末内の撮影・写真確認を試せる。写真・GPSの画面からの送信・判定・保存は未接続。

T02は共通型`PublicQuest`を表示する`QuestDetails`へ分離済み。認証後に問題ID・版を渡す接続口を用意する。最新mainのChallenge作成APIと撮影入口を維持し、APIモードでは選択中の問題ID・版で開始を確認してから撮影へ進む。判定・保存は未接続。ローカル公開APIの応答自体は架空データ。APIモードでは静的地図のマーカーを隠す。詳細と検証範囲は[B担当の実装範囲](b-development.md)を参照する。

B担当が実地図へ接続する際も、[共通API](api.md#8-最初の共通api実装)の公開探索エリアの代表点と非公開の正解地点を分ける。旧デモの表示位置を実データとして流用しない。

## 地形の出典

地図のSVGは[Natural Earthの1:110m国境データ](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)から、日本と周辺の地形をMercator投影して簡略化した。データは[パブリックドメイン](https://www.naturalearthdata.com/about/terms-of-use/)。SVG内にも取得元と取得データのSHA256を記録した。

- [`japan-overview.svg`](../src/assets/japan-overview.svg)：スマホ向け。
- [`japan-overview-wide.svg`](../src/assets/japan-overview-wide.svg)：同じ地形を横長に配置したPC向け。

低解像度の概観であり、小島や境界の精密な表示には使わない。正解位置、実写真、個人の行動履歴は含まない。コンパス等の小さなアイコンはコードで作成し、外部画像や新しい依存パッケージは追加していない。

## 確認範囲

`npm run check`で型・lint・自動テスト・ビルドを確認する。最新の件数と実施結果は[B担当の検証記録](b-development.md#今回の検証2026-11-05)に記載する。API取得、地域絞り込み、0件・失敗・再試行、古い応答の破棄、問題ID・版の引き渡しをテストする。地図の倍率と旧単体デモのマーカー操作も回帰テストを維持する。

静的地図UIを作成した際には、1440px・375px・320px幅で表示、旧マーカーからの移動、拡大・復帰を確認した。これは公開API接続・地域絞り込み追加前の記録。今回の認証変更はApp内の選択状態と受け渡し処理で、Firebase認証SDKは変更していない。実スマートフォンと今回の実Googleログインは未検証。
