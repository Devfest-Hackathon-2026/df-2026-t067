# 開発用の回答処理接続

**目的:** A待ちの回答処理を進め、受付・GPS・写真照合・本人記録ストアをサーバー内部でつなぐ。

**根拠:** [回答処理設計](../../architecture.md#4-回答処理)、[本人保存境界](../../owner-discoveries.md#aの保存処理との接続境界)、FR-06/07/08・AT-10/12/18/19/22。単独で実装する。

**範囲:** `server/src/answer-processing.ts`、`answers.ts`の内部用receipt情報、`discoveries.ts`の本人place lookup、合成画像テストと資料。HTTP・公開DTO・UI・依存は維持する。実Vertex/実写真/実クラウドの利用を有効にしない。

**設計:** 既存受付の所有者/challenge/digest/受信日時へ処理を結び付ける。非公開の公開版・参考写真・特徴・GPS条件・記録snapshotはサーバーだけから渡す。同じ回答の処理と結果を上限付きで共有し、GPS不合格ではmatcherを呼ばない。画像照合後に再認証し、最新の公開状態・版・snapshotを再確認した直後、同期的に動く開発用初回保存を呼ぶ。成功は内部のmemory結果だけで、CORRECTにしない。永続化では状態確認と記録確定を同じtransactionへ移す必要がある。
